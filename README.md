## 📚 Book4U - Персонализированная система рекомендаций книг
Book4U - это интеллектуальная система рекомендаций книг, которая использует машинное обучение для подбора литературы, соответствующей вашим вкусовым предпочтениям.

### 🎯 Основная идея
Система анализирует ваши литературные предпочтения и с помощью алгоритмов машинного обучения подбирает книги, которые с наибольшей вероятностью вам понравятся. Чем больше книг вы оцените, тем точнее становятся рекомендации!

### 🧠 Как работает машинное обучение
1. Сбор данных о предпочтениях
- Вы выбираете книги, которые вам нравятся
- Система анализирует жанры, авторов и стили выбранных произведений
- Формируется ваш уникальный "литературный профиль"

2. Обучение модели
```python
# Псевдокод процесса обучения
def train_model(selected_books):
    # Анализ характеристик выбранных книг
    features = extract_features(selected_books)
    
    # Построение модели предпочтений пользователя
    user_profile = build_user_profile(features)
    
    # Сопоставление с базой книг
    recommendations = find_similar_books(user_profile)
    
    return recommendations
```

3. Алгоритм рекомендаций
Система использует несколько подходов:
- Контентная фильтрация - анализ схожести книг по жанрам, темам, стилю
- Коллаборативная фильтрация - сравнение с предпочтениями похожих пользователей
- Гибридный подход - комбинация методов для максимальной точности

### 🚀 Возможности системы
#### 📊 Персонализированные рекомендации
- Точный подбор книг на основе ваших предпочтений

- Быстрый поиск по названиям и авторам

### 🛠 Технологический стек
- Backend: FastAPI, Python 3.8+
- Машинное обучение: Scikit-learn, Pandas, NumPy
- База данных: SQLite с SQLAlchemy ORM
- Frontend: HTML5, CSS3, JavaScript
- Шаблоны: Jinja2
- Аутентификация: Сессионные токены с шифрованием

📈 Как начать использовать
1. Регистрация и вход. 
   - Создайте аккаунт с email и паролем. 
   - Войдите в систему для доступа к персонализированным функциям

2. Первоначальная настройка вкусов
   - Выберите 10-20 книг, которые вам нравятся 
   - Система проанализирует ваши предпочтения 
   - Построит первоначальную модель рекомендаций

3. Получение рекомендаций 
   - Перейдите в раздел "Рекомендации"
   - Получите список из 30 книг, подобранных специально для вас 
   - Оценивайте рекомендации для улучшения точности

4. Уточнение предпочтений 
   - Регулярно обновляйте список понравившихся книг 
   - Удаляйте книги, которые не соответствуют вашим вкусам 
   - Наблюдайте, как рекомендации становятся точнее

## 🔧 Установка и запуск
### Локальная установка
```python
# Требования 
# Python 3.8 или выше
# pip (менеджер пакетов Python)

# Клонирование репозитория
git clone https://github.com/StasyStar/BookRecommend.git
cd BookRecommend

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python run.py

# Открыть браузер и перейти по адресу
# http://0.0.0.0:8000 либо 
# http://localhost:8000
```
### Запуск с помощью Docker
```python
# Сборка образа
docker build -t book4u .

# Запуск контейнера
docker run -d -p 8000:8000 --name book4u-app book4u

# Открыть браузер и перейти по адресу
# http://localhost:8000
```
